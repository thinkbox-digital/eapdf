# EA-PDF Validator

Check that an EA-PDF file follows the format requirements. The validator shows the results and lets you save a report.

[Download the Validator](https://github.com/thinkbox-digital/eapdf/releases/download/v2.4.0-beta.3/eapdf-validator-2.4.0-beta.3.jar), then double-click the JAR to open it. It requires a desktop version of Java 21 or later. Choose a PDF and start validation. See the [user manual](../docs/manual/user-manual.html#java-validator) for help reading the report.

To browse messages and attachments, open the PDF in [Desktop Viewer](https://github.com/thinkbox-digital/eapdf/releases/download/v2.4.0-beta.3/eapdf-desktop-viewer-full-0.8.0.jar). See the [technical guide](TECHNICAL_GUIDE.md) for automation, checks and build details.
