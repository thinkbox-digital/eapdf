# Reader beta

Full and Even More Lite readers **1.3.0-beta.1** are included with **EA-PDF 2.3.0-beta.1**.

Get the browser ZIP from the [release page](https://github.com/thinkbox-digital/eapdf/releases/tag/v2.3.0-beta.1),
then follow the [installation guide](../README.md#install).

Full includes search, filtering, independent CSV/XMP export, Conversations, Portfolio
layouts, embedded indexes and larger-archive support. Even More Lite provides
message/folder navigation, pages and embedded assets in three adjustable panes.
It accepts PDFs up to 32 MiB and 2,048 pages. Viewer Lite is no longer built or published.

See [release checks](../../docs/releases/2.3.0-beta.1-validation.md) for verified scope.
These are unsigned beta extensions; Firefox installation is temporary. A readable
PDF does not establish EA-PDF conformance or human accessibility.
