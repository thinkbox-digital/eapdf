# Frozen browser regression inputs

These are byte-for-byte copies of the earlier EML demonstration PDFs and their
manifest, retained when the user-facing examples were rebuilt from real emails
on 2026-10-28. The 27 independent expected inspection records are unchanged.
They are test inputs, not the current demonstration set. Current examples are
under the repository `examples/` directory. Original MSG/PST files used by attachment checks are likewise retained under
`tests/attachments/source/`. Every copied PDF is checked against its frozen hash.
