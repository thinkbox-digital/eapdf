# Full browser reader

Read EA-PDF archives in Chromium or Firefox. Open a PDF, browse its messages and folders, and view or save attachments.

Download the [Chromium or Firefox package](https://github.com/thinkbox-digital/eapdf/releases/tag/v2.4.0-beta.4) and follow the [browser installation guide](../docs/manual/user-manual.html#viewer). To open PDFs in a separate app, use [Desktop Viewer](https://github.com/thinkbox-digital/eapdf/releases/download/v2.4.0-beta.4/eapdf-desktop-viewer-full-0.9.0.jar).
