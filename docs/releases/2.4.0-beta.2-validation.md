# Release checks for 2.4.0-beta.2

The creator and validator use Java 21. Both reader profiles use version 1.7.0.
The software architecture diagram and user manual passed PDF/A-2b validation.
The public documentation passed the repository privacy check.

The release uses the previously published example PDFs and screenshots.
Browser-store signing, live Gmail onboarding, and human accessibility review
require separate checks.

The bundled DejaVu Sans change was reviewed on six pages from the public EML,
MSG and MBOX acceptance corpus. Text widths and header wrapping changed. The
source fidelity checks, page counts, and standalone EA-PDF and PDF/A validation
passed. Only the reviewed visual references changed.
