EA-PDF Main 2.4.0-beta.5 is a prerelease. It includes the Full browser reader 1.10.0 and Desktop Viewer 0.9.0.

- Multi-file conversions publish a manifest that selects one complete batch. Regeneration verifies those files before publication.
- Mail parsing, rendering, and validation enforce resource limits and preserve inputs across failed jobs.
- Gmail supports encrypted token persistence through `EAPDF_GMAIL_TOKEN_PASSWORD`.

Install Java 21 or later for the Creator, Validator, and Desktop Viewer.
