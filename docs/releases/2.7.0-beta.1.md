EA-PDF Main 2.7.0-beta.1 is a prerelease. It includes Full Browser Viewer 1.15.0 and Desktop Viewer 0.11.0.

- The Creator reports more stages during archive creation. PST conversions use the stored transport headers to populate message fields and retain reconstructed EML in retained-source profiles.
- The Validator shares the PDF/A-4f and ISO 32005 traversal on eligible PDFs, caches rule lookups, and reports progress while checking embedded files.
- The Desktop Viewer opens large archives with less parser memory, updates the message filter in one operation, and reuses a verified embedded search index during the session.

Install Java 21 or later for the Creator, Validator, and Desktop Viewer.
