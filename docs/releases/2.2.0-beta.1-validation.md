## Web workbench removal

Removed validator_web.py, eapdf_web/, server deployment files, web screenshots and
web-only tests. Flask, Gunicorn and Werkzeug are no longer runtime requirements.
The Python CLI keeps requirements-validator.txt and its hash lock for regression
tests and diagnostics. The Java validator and full/Lite readers remain the user tools.
