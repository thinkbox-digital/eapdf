# EA-PDF 1.6.0-beta.9

Creator and validator 1.6.0-beta.9; viewer 0.5.0-beta.8.

Includes MBOX/PST process workers, four-process collection validation, and the
recent viewer search, navigation, export, and layout fixes. The viewer accepts
root files up to 4 GiB; parsing a file of that size is not guaranteed.

Verification: 390 creator tests (four optional skips), 262 validator tests
(nine optional skips), zero failures/errors; 55 viewer unit tests and four
Chromium integration suites passed. Five real EML/MSG/MBOX/PST regressions
passed fidelity, visual and standalone Java validation checks. All 25 generated
documentation pages passed local link and asset checks. Full beta smoke testing
is blocked by the absent output/bfo.pdf fixture; Firefox packages are built
but this release runtime regression used Chromium.

Examples and supporting documents retain their prior editions and original
bytes; they were not regenerated for this release. The example bundle includes
an intentionally missing-date negative example. Large-archive validation is
still running and earlier failures/incomplete findings remain documented in
[development status](../DEVELOPMENT_STATUS.md). No all-pass corpus claim is made.

Local build logs, source hashes, conversion reports, runtime inventories, and
upload verification: output/release-1.6.0-beta.9/.
