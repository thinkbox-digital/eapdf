# Release checks: 2.3.0-beta.1

Verified on Linux, 18 November 2026. Creator/validator 2.3.0-beta.1; Full and
Even More Lite readers 1.3.0-beta.1. Even More Lite replaces Lite packages.
C2PA/PAdES, WeasyPrint and other experimental features remain separate.

## Java and conversion checks

- Creator: 435 tests passed; one optional desktop workflow skipped.
- Validator: 291 tests passed, including executable-JAR packaging; two optional
  checks skipped (desktop workflow and a separately supplied nested Outlook fixture).
- The retained local edge-case/legacy corpus enabled preservation and ownership
  regressions. Those fixture files and their hashes remain local; they are not
  new product features or release assets. Missing fixture data and inherited
  global Python imports were corrected before acceptance; passed stages were
  retained when the release gate resumed.
- All three distributable JARs match independent repeat builds. Only versioned
  creator, GUI and validator JARs are installed in dist.
- Three public EML/MSG/MBOX cases passed independent content checks, unchanged
  six-page visual baselines and standalone Java EA-PDF/PDF/A validation.
- Four additional real inputs under in/ cover EML 1s, MSG 1si, whole-source MBOX
  1mi and whole-source PST 1ci. All passed standalone Java EA-PDF/PDF/A validation.
  Original hashes are unchanged; no selected input was rejected or incomplete.
  Accessibility was enabled, optional PREMIS disabled and processing bounded.
- The hash-locked Python CLI environment passed 48 regression tests and eight
  release-oracle tests. The independent inspection environment passed 15 Python
  tests, two contract tests and all 27 frozen records/provenance checks.

## Readers and documentation

Full passed 192 Node tests, its Chromium and Firefox acceptance suites, and the
archive-memory regression. The Firefox harness now supplies the required system
access flag itself. Optional private Portfolio coverage remains outside this run.

Even More Lite passed five standalone tests, eight Chromium/web acceptance checks
and two Firefox acceptance checks. Coverage includes three adjustable panes,
rendering, text selection, navigation, original-byte asset downloads, previews,
embedded links, limits, cancellation and recovery. Its transferred application
measures 1,973 physical / 1,926 nonblank source lines including shared modules.
Full retains search, filtering and independent CSV/XMP export.

The generic PDF.js source changes passed 44 Full and 17 generic-hook tests,
141 upstream specs and clean byte-for-byte bundle reproduction. One upstream
spec remains pending because Node lacks OffscreenCanvas. The source pin remains
PDF.js 6.5.438. Equivalent font-name quote character classes are recorded in
source patch 0012. Full Qodana analysis has not been rerun; generated-worker IDE
inspection timed out, while the reported Java findings were cleared.

The current user manual and architecture diagram pass PDF/A-2b validation.
Architecture arrows point downward from each tool to its libraries. The strict
website build checks 30 pages and all local links/assets; documentation privacy
checks pass. Runtime dependency versions are unchanged; inventories identify the
new application version and tested JAR hashes.

The example archive and legal-notice bundle retain their verified published bytes
from the predecessor. The screenshot set replaces Lite with the current Even More
Lite control-document view; the other screenshots remain dated earlier sessions.
Private source email and local evidence are not published.

Readers are unsigned beta extensions; Firefox installation is temporary. These
checks do not certify browser-store packaging, other operating systems, live Gmail
onboarding, signer trust or human accessibility.
