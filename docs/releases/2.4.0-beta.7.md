EA-PDF Main 2.4.0-beta.7 is a prerelease. It includes the Full browser reader 1.12.0 and Desktop Viewer 0.9.1.

- The README shows the Desktop Viewer displaying an anonymized email from a combined archive. Download the examples ZIP to try all six EA-PDF profiles.
- GitHub Pages refreshes the desktop screenshot from the current build on every push to Main.

Install Java 21 or later for the Creator, Validator, and Desktop Viewer.
