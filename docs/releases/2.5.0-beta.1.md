EA-PDF Main 2.5.0-beta.1 is a prerelease. It includes Full Browser Viewer 1.14.0 and Desktop Viewer 0.10.0.

- The Creator releases staged message data earlier and stops MBOX workers that stop making progress.
- The Validator handles more malformed PDF streams explicitly and respects inherited Linux worker limits.
- The Desktop Viewer bounds attachment and metadata decoding. Returning to a parent PDF leaves the interface responsive.
- The Full Browser Viewer reports incomplete file inventories when inspection limits are reached.

Install Java 21 or later for the Creator, Validator, and Desktop Viewer.
