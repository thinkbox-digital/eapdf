EA-PDF Main 2.4.0-beta.6 is a prerelease. It includes the Full browser reader 1.11.0 and Desktop Viewer 0.9.1.

- Combined archives and collections choose rendering workers based on extracted message size, including for messages read from whole mailboxes.
- Creator keeps optional features off when the GUI opens, improves the incomplete-source notice, and preserves available content when it encounters malformed MIME.
- Desktop Viewer improves attachment image previews and makes it easier to cancel opening a PDF.

Install Java 21 or later for the Creator, Validator, and Desktop Viewer.
