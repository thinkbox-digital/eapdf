# EA-PDF 1.6.0-beta.18

Creator and validator **1.6.0-beta.18**; viewer **0.5.0-beta.17**.

- Optional embedded archive search indexes; no Node.js required for conversion.
- Improved search matching, highlighting, CSV export and keyboard navigation.
- Filename navigation returns to the first page at Fit Width; the opened filename stays visible.
- Creator search-index checkbox, finding aids off by default, and lower MIME parsing allocations.

Java 21+ is required for the creator and validator. Replace old viewer extension files and reopen viewer tabs; Firefox packages use temporary unsigned installation.

Beta release. Large-archive, source-validation and cross-platform limitations remain documented. Index generation may be omitted with a diagnostic when resource limits apply.
