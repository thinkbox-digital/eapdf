# EA-PDF 1.6.0-beta.20

Creator and validator **1.6.0-beta.20**; viewer **0.5.0-beta.20**.

- Fix message arrows and filtering; make attachment previews easier to close.
- Improve large-file responsiveness and embedded filtering indexes; retain CSV export.
- Remove creator Branding, Finding Aid and PREMIS options; default creator to Thinkbox.DIGITAL.
- Add parallel sample/full regeneration with per-job PDF publication, and update web parser/security fixes.

Java 21+ is required. Reload the updated viewer extension and reopen old viewer tabs. Firefox remains temporary and unsigned. Regenerate older PDFs to add the new filtering index.

Beta release; documented validation and large-file limitations remain.
