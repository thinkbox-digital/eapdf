EA-PDF 2.4.0-beta.3 is a prerelease. It includes the Full browser reader 1.8.0.

- Desktop Viewer 0.8.0 opens local EA-PDF archives and PDF Portfolios. It supports message and attachment navigation, search, and CSV/XMP export.
- The Java validator improves metadata cross-checking.

Use Java 21 or later for the creator, validator and desktop viewer. Extract the configuration ZIP beside the creator. Double-click the Desktop Viewer JAR, then choose **Open PDF…**.
