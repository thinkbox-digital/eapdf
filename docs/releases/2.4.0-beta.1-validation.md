# Release checks for 2.4.0-beta.1

Builds use Java 21 on Linux. The browser distributables are Full and Even More
Lite 1.6.0-beta.1. Local browser profile directories retain their existing paths.

The tagged source includes the paired veraPDF parser 1.31.72 and validation-model
1.31.225 update, OpenHTMLtoPDF 1.1.114-eapdf.1, FontBox 3.0.8-eapdf.1, and the
embedded font fix in both PDF.js 6.5.438 worker recipes.

The previous release's published example PDFs are reused. Live Gmail onboarding,
macOS Firefox rendering, browser-store signing and human accessibility review
are outside the verification scope.

- Maven verification passed 440 creator tests and 207 validator tests. The
  suites skipped 46 and 97 checks, respectively, including optional local
  fixtures. Standalone Java validation passed all four signed-index profiles.
- Full passed 192 reader unit tests and 16 offline beta checks. Both PDF.js
  generated bundles matched their pinned recipes.
- The regenerated user manual and software architecture diagram passed PDF/A-2b
  validation. The architecture arrows run down from each tool to its libraries.
