# Release checks — 14 November 2026

Creator/validator 2.2.0-beta.3; full/Lite readers 1.2.0-beta.3.

## Bug fixes

Message downloads copy original bytes only after a declared standalone profile,
complete relevant inspection, one recognized message and proven ownership of all
pages. Partial 1m/1mi inspections export proven body pages or disable the action.
Portfolio's explicit Download active file continues to preserve the original PDF.
Patch 0011 supplies opt-in page-only extraction that omits inherited embedded
files, metadata, annotations, structure tags and DPart back-references. The distinct
worker action fails closed with an older worker. Default PDF.js extraction is
unchanged. Tests check private source payloads, page AF, annotations, archive
metadata and Info, plus selected-page text and pixel equality.

Both workers backport [Mozilla PDF.js PR #22521](https://github.com/mozilla/pdf.js/pull/22521),
merge `5f2d7186f72c87e40150314c5cf856133f0b2466`, through patch 0010. Source
hashes, both generated bundle hashes and the Lite selection recipe are updated.
The base stays PDF.js 6.5.438. No speed or memory improvement is claimed.

## Verification

All 192 Full unit tests and 16 standalone Lite tests pass. The Full source build
runs 142 upstream specs with zero failures and one existing Node OffscreenCanvas
pending. Lite's 17 hook regressions pass. Chromium 156 and Firefox 160 check both

pass PDF/A validation. Runtime inventories are refreshed for this version.
