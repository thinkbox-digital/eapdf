# EA-PDF 2.0.0-beta.1

Creator and validator **2.0.0-beta.1**; viewer **1.0.0-beta.1**.

- Improve PDF Portfolio layouts, message navigation, folder breadcrumbs, file drops and attachment controls.
- Fix nested Outlook attachment comparisons and handling of large metadata and validation reports.
- Show visible review warnings after failed or unfinished validation.

Java 21+ is required. Reload the viewer extension and reopen viewer tabs. Restart web services to load updated workers. Firefox remains temporary and unsigned.

Major-version beta release; incomplete source data and documented validation limitations remain. The example bundle retains its recorded earlier provenance.
