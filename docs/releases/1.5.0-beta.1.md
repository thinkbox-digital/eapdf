# EA-PDF 1.5.0-beta.1 (Beta)

Beta release for ordinary email creation and EA-PDF validation. **Java 21 or later is required.**

## Downloads

- `emailtopdfa-1.5.0-beta.1-gui.jar`: desktop email creator.
- `emailtopdfa-1.5.0-beta.1.jar`: command-line creator, including Gmail workflows.
- `eapdf-validator-1.5.0-beta.1.jar`: standalone desktop validator with its PDF/A engine, selected ISO 32005 profile, libraries and rules included.

Run a desktop app with `java -jar downloaded-file.jar`. The CLI uses the arguments documented in the repository README. Each JAR includes its runtime dependencies.

## Changes since v1.3.1

- Improve EML, MSG, PST, MBOX and Gmail creation, source preservation, body rendering and archive resource use.
- Correct adjacent encoded subject words, native Outlook recipient order and stored sent timestamps.
- Add the standalone Java validator and use 213 specification-ordered EA-PDF rules, with development review records stored separately.
- Repair source/attachment ownership comparisons and retain explicit incomplete results when required evidence is unavailable.
- Include the specification-author review document with verified source quotations, complete relevant table rows and all 19 original source tables.

## Verification

The published application source passed 277 creator tests, 154 standalone-validator tests (one optional desktop smoke check skipped), and 1,142 Python tests (40 optional checks skipped). Packaged artifacts are checked separately before upload.

## Beta limits

Known limits remain for missing-header/unsupported MSG comparisons, PST reconstructed timestamp precision, absent remote assets, very large archives and recorded specification ambiguities. This is not complete standards or accessibility certification.

`EA_PDF_Rule_Review_for_Specification_Authors.docx` is included for review in Word or Google Docs. `licenses-and-notices-1.5.0-beta.1.zip` accompanies the JARs; notices are also retained inside the artifacts. Verify downloaded assets using `SHA256SUMS.txt`.
