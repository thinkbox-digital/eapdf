EA-PDF creator and validator **1.6.0-beta.4**.

- Lower memory use during email conversion and PDF validation.
- Improved rendering and archive-index generation.
- Refreshed EML, MSG, small-PST and MBOX examples with validation manifests.

Requires **Java 21+**. Set **Creator identity…** in the GUI or `creator` in the configuration before converting. Large archives need sufficient RAM.

This remains a beta. The viewer stays at **0.4.0-beta.1**, available from the previous release.
