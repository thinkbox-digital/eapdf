# Reference documents

licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
The original PDF retains its attribution and license notice. Project explanations
and rule extractions are identified separately from the specification.

ISO standards are not distributed from this folder. Obtain authorized copies
from ISO or the [PDF Association sponsored standards programme](https://pdfa.org/sponsored-standards/).
A free download does not, by itself, establish permission to redistribute it.
Local `ISO*.pdf` files are ignored. Some specification-audit authoring scripts
require those local references; ordinary builds and CI do not.

The superseded local `Validation requirements.docx` draft is not distributed.
Generated rule-review documents draw on the attributed EA-PDF specification.
