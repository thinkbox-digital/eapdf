# Email to EA-PDF

Convert saved emails and mailboxes into readable preservation PDFs, check the
results, and browse messages and attachments. Created by **Thinkbox.DIGITAL**.

[Get started](manual/installation.md){ .md-button .md-button--primary }
[Download the applications](downloads.md){ .md-button }

## From email to a checked PDF

1. **Choose your output.** Start with [the guide to files and profiles](manual/basics.md).
   Inputs include EML, MSG, PST, MBOX and Gmail.
2. **Convert your email.** Follow the [desktop creator walkthrough](manual/creator.md),
   then read its conversion warnings.
3. **Check the result.** Run the [standalone Java validator](manual/java-validator.md)
   and save its report. Opening a PDF successfully is not a validation check.
4. **Read and explore.** Use the [viewer](manual/viewer.md) to browse messages,
   collection folders and embedded files.

## Keep the originals

For PST, MBOX and Gmail, embedded message sources are exported or reconstructed
messages, not the complete original mailbox. Keep your original files separately.
Isolated profiles deliberately omit source assets; they do not anonymize the email.
