# Downloads

Download **EA-PDF 1.6.0-beta.8** and **viewer 0.5.0-beta.6** from the
[current release](https://github.com/thinkbox-digital/eapdf/releases/tag/v1.6.0-beta.8).

| File | Use it for |
| --- | --- |
| `emailtopdfa-1.6.0-beta.8-gui.jar` | Desktop email conversion |
| `emailtopdfa-1.6.0-beta.8.jar` | Command-line conversion |
| `eapdf-validator-1.6.0-beta.8.jar` | Standalone Java validation |
| `configuration-1.6.0-beta.8.zip` | Public application configuration |
| `eapdf-viewer-0.5.0-beta.6-chromium.zip` | Chromium viewer extension |
| `eapdf-viewer-0.5.0-beta.6-firefox.zip` | Firefox viewer extension |
| `ea-pdf-examples-1.6.0-beta.8.zip` | Example outputs and validation records |
| `EA-PDF_User_Manual.pdf` | Offline PDF/A user manual |
| `SHA256SUMS.txt` | Checksums for verifying the downloaded files |

Java applications require **Java 21 or later**. Extract the configuration bundle
beside the JARs and set your creator identity. Follow the
[installation guide](manual/installation.md) before converting.

Viewer packages are unsigned and require manual installation. Firefox uses a
temporary installation. See [viewer instructions](manual/viewer.md).

The release also includes specification review documents and dependency notices.
Project-maintained patched libraries are distributed through
[GitHub Packages](https://github.com/thinkbox-digital/eapdf/packages);
see [library usage](developers/packages.md).
