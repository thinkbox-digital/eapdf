# Downloads

Download the apps from the [EA-PDF Main 2.4.0-beta.7 release](https://github.com/thinkbox-digital/eapdf/releases/tag/v2.4.0-beta.7).

| App | Use it to |
| --- | --- |
| [Desktop Viewer](https://github.com/thinkbox-digital/eapdf/releases/download/v2.4.0-beta.7/eapdf-desktop-viewer-full-0.9.1.jar) | Open PDFs, browse email and attachments, and save files. |
| [Creator](https://github.com/thinkbox-digital/eapdf/releases/download/v2.4.0-beta.7/emailtopdfa-2.4.0-beta.7-gui.jar) | Convert email to PDF in a desktop window. |
| [Validator](https://github.com/thinkbox-digital/eapdf/releases/download/v2.4.0-beta.7/eapdf-validator-2.4.0-beta.7.jar) | Check a PDF and save a report. |
| Full browser reader for [Chromium](https://github.com/thinkbox-digital/eapdf/releases/download/v2.4.0-beta.7/eapdf-viewer-1.12.0-chromium.zip) or [Firefox](https://github.com/thinkbox-digital/eapdf/releases/download/v2.4.0-beta.7/eapdf-viewer-1.12.0-firefox.zip) | Read PDFs in your browser. |

Desktop apps require a desktop version of Java 21 or later. Double-click a downloaded JAR to open it. For help, see [Get the tools ready](manual/installation.md).
