# Downloads

Download **EA-PDF 2.0.0-beta.1** and **viewer 1.0.0-beta.1** from the
[current release](https://github.com/thinkbox-digital/eapdf/releases/tag/v2.0.0-beta.1).

| File | Use it for |
| --- | --- |
| `emailtopdfa-2.0.0-beta.1-gui.jar` | Desktop email conversion |
| `emailtopdfa-2.0.0-beta.1.jar` | Command-line conversion |
| `eapdf-validator-2.0.0-beta.1.jar` | Standalone Java validation |
| `configuration-2.0.0-beta.1.zip` | Public application configuration |
| `eapdf-viewer-1.0.0-beta.1-chromium.zip` | Chromium viewer extension |
| `eapdf-viewer-1.0.0-beta.1-firefox.zip` | Firefox viewer extension |
| `ea-pdf-examples-2.0.0-beta.1.zip` | Example outputs and validation records |
| `EA-PDF_User_Manual-2.0.0-beta.1.pdf` | Offline PDF/A user manual |
| `SHA256SUMS.txt` | Checksums for verifying the downloaded files |

Java applications require **Java 21 or later**. Extract the configuration bundle
beside the JARs. The creator defaults to `Thinkbox.DIGITAL`. Follow the
[installation guide](manual/installation.md) before converting.

Viewer packages are unsigned and require manual installation. Firefox uses a
temporary installation. See [viewer instructions](manual/viewer.md).

The release also includes specification review documents and dependency notices.
Project-maintained patched libraries are distributed through
[GitHub Packages](https://github.com/thinkbox-digital/eapdf/packages);
see [library usage](developers/packages.md).
