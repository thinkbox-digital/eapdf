# Downloads

Download the apps from the [EA-PDF Main 2.7.0-beta.1 release](https://github.com/thinkbox-digital/eapdf/releases/tag/v2.7.0-beta.1).

| App | Use it to |
| --- | --- |
| [Desktop Viewer](https://github.com/thinkbox-digital/eapdf/releases/download/v2.7.0-beta.1/eapdf-desktop-viewer-full-0.11.0.jar) | Open PDFs, browse email and attachments, and save files. |
| [Creator](https://github.com/thinkbox-digital/eapdf/releases/download/v2.7.0-beta.1/emailtopdfa-2.7.0-beta.1-gui.jar) | Convert email to PDF in a desktop window. |
| [Validator](https://github.com/thinkbox-digital/eapdf/releases/download/v2.7.0-beta.1/eapdf-validator-2.7.0-beta.1.jar) | Check a PDF and save a report. |
| Full browser reader for [Chromium](https://github.com/thinkbox-digital/eapdf/releases/download/v2.7.0-beta.1/eapdf-viewer-1.15.0-chromium.zip) or [Firefox](https://github.com/thinkbox-digital/eapdf/releases/download/v2.7.0-beta.1/eapdf-viewer-1.15.0-firefox.zip) | Read PDFs in your browser. |

Desktop apps require a desktop version of Java 21 or later. Double-click a downloaded JAR to open it. For help, see [Get the tools ready](manual/installation.md).
