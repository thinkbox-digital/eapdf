# EA-PDF validation requirements

The published EA-PDF specification is the authority for requirements. Runtime
rule descriptions are maintained in [validator_rule_text.json](../validator_rule_text.json).
Local implementation decisions do not amend the standard.

Validation covers profile identification, metadata, document parts, collections,
logical structure, source assets and attachment relationships. Applicability and
available evidence determine which checks can complete. See
[coverage and limitations](VALIDATOR_COVERAGE.md) and the
[standalone validator instructions](../validator-desktop/README.md).
