How to use this page

Select a rule or scroll either pane. With Sync panes on, the other pane follows. Use ↑ / ↓ or J / K to move between rules.

Each rule states the requirement once. Page buttons open the source; Checks lists check codes. Search also matches the full rule wording.

Source highlights: table matches use the original field or group. Other matches are suggestions and need review. All cited pages are available in Details.

Terms: XMP is PDF metadata. DPart groups pages by email and content. A Content Set is a related group of pages. FOAF describes people and email addresses. Bag is an unordered list; Seq is an ordered list.

Profiles: s = one email; m = multiple emails; c = collection. Add i when the original source link is missing or unreliable.

The original specification is unchanged. The Mail_ContentField → Mail_Field correction is user-approved, not published errata. Open issue reports do not change the rules. Linked checks do not prove full coverage.
