# Security reporting

EA-PDF is beta software that processes untrusted email, PDF and embedded files.
Security boundaries and known limits are documented in [HARDENING.md](docs/security/HARDENING.md)
and the [viewer security notes](browser-viewer/docs/security.md).

Do not disclose vulnerabilities, credentials, private email or malicious samples
in public issues. GitHub private vulnerability reporting is enabled. Use
[Report a vulnerability](https://github.com/thinkbox-digital/eapdf/security/advisories/new).
If that option is unavailable, arrange a private reporting channel with the
repository owner before sending sensitive details. No public reporting channel
should be used as a substitute.

Include the affected version, steps to reproduce and a minimal non-sensitive
sample when possible. The current beta is the maintenance target; older releases
are not supported. This project does not promise a response-time SLA.

Private vulnerability reporting was enabled for the public repository on
2 November 2026.
